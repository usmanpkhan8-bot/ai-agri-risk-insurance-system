# 🌾 AI Agri Risk Insurance System

An AI-powered system for predicting agricultural risks and triggering insurance alerts using machine learning, weather, and crop data.

---

## 🚀 Features
- 🌦 Weather data integration using API
- 🌱 Crop yield prediction using ML models
- 💰 Insurance premium calculation
- 📊 Year-wise agricultural risk comparison
- ⚠️ Early warning system for crop risk

---

## 🧠 Technologies Used
- Python
- Machine Learning
- XGBoost (or ML models)
- Pandas, NumPy
- API Integration

---

## 📂 Project Structure
- `weather_api.py` → Fetches weather data  
- `yield_forecast.py` → Predicts crop yield  
- `premium_calculator.py` → Calculates insurance premium  
- `year_comparison.py` → Compares agricultural data
